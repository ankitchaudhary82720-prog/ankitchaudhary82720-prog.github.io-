# Ankit Chaudhary — Developer Portfolio

A responsive dark-themed personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current year
- `resume.txt` — editable starter resume

## Personalize before publishing
1. Replace `YOUR_EMAIL@example.com` and `YOUR_EMAIL@gmail.com` with your real email.
2. Replace the LinkedIn homepage link with your actual LinkedIn profile URL.
3. Review the skills and remove anything you have not worked with.
4. Update project descriptions and add links to the actual project repositories.
5. Edit `resume.txt` with your correct college, graduation year, contact details, certifications, and achievements.

## Publish with GitHub Pages
1. Create a public repository named exactly `ankitchaudhary82720-prog.github.io`.
2. Upload all four files (`index.html`, `styles.css`, `script.js`, `resume.txt`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment, visit: https://ankitchaudhary82720-prog.github.io/

The resume download currently downloads an editable text starter, not a finished verified CV. Replace it with a polished PDF later if desired.
